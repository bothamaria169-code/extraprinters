## How to use

1. In your image generator, **attach the logo** (`Vibrant Extra Printers Logo.png`) so it copies the real logo.
2. Paste the **style line**, then the product prompt.
3. Save each image as the **file name** shown (square, 1200 × 1200 px, JPG).
4. Then either drop the files into the project folder and tell Claude, **or** go to 🟩 Admin → Products → Edit → Photos → Upload.

**Style line (paste before every prompt):**

```
Photorealistic product mockup, square 1:1, 1200x1200. Clean bright white studio background with soft shadows and subtle flowing ribbons in cyan, magenta, yellow and royal blue (the Extra Printers CMYK colours). Use the attached Extra Printers logo exactly as given (colourful four-petal X mark with "EXTRA PRINTERS" wordmark). Sharp focus, premium commercial look, no other brand names, no watermarks, no extra text unless asked.
```

**Tips**
- AI generators sometimes misspell text. Check that "EXTRA PRINTERS" and any sizes (A4, 350gsm) are spelled correctly, and regenerate if not.
- Keep the background light and the product centred. Square cards crop the edges.
- Real job photos beat mockups for Google. Swap in photos of finished jobs whenever you have them.
